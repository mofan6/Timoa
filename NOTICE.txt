功能包括倒计时、正计时、精简悬浮窗、闹钟、每周计划、数据迁移、音频导入与 Windows 托盘。
应用调用的系统字体属于 Windows，不随软件重新分发。
中文界面使用更纱黑体 Sarasa UI SC 的 Regular / Bold 字库子集，英文采用 Segoe UI。
Sarasa Gothic Copyright (c) 2015-2025 Renzhi Li 及各上游项目，采用 SIL Open Font License 1.1。
完整版权声明与许可见 licenses/Sarasa-Gothic-OFL.txt。
官方来源、原始与裁切文件校验记录见 assets/fonts/manifest.json。
字库保留界面全部简繁中文与英文用字、适量常用字和常见符号，保留 hinting。
自定义名称中未内置的字由系统字体补齐；开发构建时可自动补入新增的界面用字。
裁切后的内部名称为 Timoa Sarasa UI SC，可用 tools/subset-ui-fonts.py 从完整原字体重新生成。
中文标题采用字体自带的 Bold 字重，文字覆盖图使用 Windows DirectWrite，失败时回退 Swash。

FFmpeg：应用内包含可替换的音频解码组件，采用 LGPL 2.1 或更高版本，
未启用 GPL / nonfree。许可与构建说明见 licenses/FFmpeg-NOTICE.txt。
对应源码、构建脚本、配置选项在本版本源码包 third-party/FFmpeg 中。
可将兼容的 ffmpeg.exe 及其依赖放在主程序旁的 codecs 目录中替换内置组件。
不使用网络音频解码，不修改导入的原文件。

其他 Rust 依赖、Windows GNU 运行时的许可见 licenses 目录。
FemtoVG 的 Windows 字形覆盖适配与原始 MIT 许可见
licenses/FemtoVG-NOTICE.txt、licenses/FemtoVG-MIT.txt 及 vendor/femtovg。

发布 EXE 使用官方未修改的 UPX 5.1.0 压缩，GPL-2.0+ 及其压缩程序特别许可。
原生程序启动时在内存中解压，不需要安装 UPX，不另行展开主程序副本。
UPX：https://github.com/upx/upx/releases/tag/v5.1.0
许可见 licenses/UPX-License.txt 与 UPX-GPL-2.0.txt。
