# 专注快捷键

- 主窗口的倒计时 / 正计时页面：1 秒内连续按三次 M，开始或继续对应计时。
- 倒计时已经完成时，三次 M 会按原时长再开一轮；正计时完成本轮后，可用三次 M 从零开始。
- 对应计时已经运行时，三次 M 不创建重复计时，也不会暂停。
- 按一次 N 只暂停当前页面对应的计时，已暂停时再次按 N 不会继续。
- 使用物理 M / N 键，不受大小写或输入语言影响。
- 组合键、长按产生的自动重复、其他页面、其他软件、悬浮窗及文字输入时不触发。
- 鼠标操作、其他按键、切换页面或窗口失焦后，清空之前的连按计数。

沿用现有计时、互斥、统计和保存逻辑；不增加新的系统全局快捷键。
