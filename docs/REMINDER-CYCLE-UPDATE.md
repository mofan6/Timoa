# 提醒、下一轮与每日专注更新 · 2026-10-17

## 行为

- 提示音在提醒到点时立即触发，不再等待旧提醒窗口关闭。关闭旧窗口不会停止较新提醒的提示音。
- 开始倒计时后，单一专注卡片 / 我的计时列表右上角显示预计结束时刻；暂停和完成状态仍清晰区分。
- 精简窗口在标题右侧显示预计结束时刻，标题较长时优先保留结束时间；暂停、未开始及正计时不显示结束时刻。
- 更多设置使用“下一轮快捷时长”名称，只保留三个分钟:秒滚轮；删除单独的默认时长和对应按钮、回调与数据字段。
- 完成提醒保留三个快捷按钮，底部为“再来一轮”和“我知道了”，文字按内容分配高度，缩减中部空白。三个快捷按钮沿用原有启动逻辑。
- 单一专注、自动循环、循环间隔与下一轮快捷时长旁提供小感叹号说明。正计时不添加说明图标。说明采用大白话，沿用 100ms 悬浮和避让鼠标的页面覆盖层。
- 自动循环默认关闭，间隔 0—3600 秒，00:00 按 1 秒处理。
- 循环开始下一轮时自动关闭对应上一轮的提醒，清理队列中的旧提醒。间隔中可暂停、重置、移除，关闭开关会取消待开始的循环。
- 正计时开始时也会暂停等待下一轮的倒计时，维持正计时 / 倒计时互斥。
- 每轮完成只统计一次；自动重启不会额外增加已完成时长。循环等待只在当前运行进程内调度，重开软件不会批量补跑离线循环。
- 一周页在当日安排上方增加每日专注卡片，展示所选日期的完成时长、轮数与 24 小时分布；悬浮柱子显示对应时段与时长，随周和日期切换。
- 柱状图固定以每小时 60 分钟为满格，纵轴标明 0、30、60 分钟，不按当天峰值拉伸。几秒钟的记录保留最小可见高度；零时长不画柱子。并行计时累计超过 60 分钟时以满格加号表示，悬浮仍显示完整时长。
- 只在倒计时自然完成、正计时选择完成本轮时计入每日统计。按有效运行时段分桶，暂停和循环等待不计入；重置、移除未完成轮次不计入。
- 运行中尚未完成的小时桶保存在快照，完成后只汇总一次。跨日记录按实际小时拆分，已有累计时长保留；旧版本未记录的每日分布不补造，从本版开始积累。
- 清除计划和恢复默认设置保留已完成统计。每日历史最多保留 3650 天。
- JSON 备份自动包含 quickSnoozeSeconds、autoCycle、cycleIntervalSeconds、focusDays 及进行中计时的 focusSlots；旧备份使用兼容默认值，旧 snoozeSeconds 字段被忽略，不再导出。
- 继续支持简体中文、繁体中文、英文与深浅色主题。
