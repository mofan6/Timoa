# 提醒窗口维护说明 · 1.3.2

提醒结束时立即清除其逻辑状态，但在当前事件回调结束后再隐藏、释放组件。
下一条提醒只由 100 ms 调度显示，避免在按钮或原生关闭事件里重入窗口系统。
每轮按需创建窗口，不复用上一轮隐藏后的原生渲染表面。

每个提醒窗口带独立代次标记。回调只处理当前窗口，已关闭窗口的迟到事件
不能影响下一轮。显示窗口时不持有 App 的 RefCell 借用；创建/显示失败时
保留提醒队列并记录日志。关闭旧提醒仍只停止其自己拥有的提示音。

Windows 后端映射窗口后主动请求重绘；应用在设置主题和位置后也请求首帧。
主题、字体、UI 布局、计时引擎和备份格式未修改。

按用户要求停止进一步窗口测试。本版本发布检查为源码审查、两架构编译、
PE/版本资源与包内容静态核对；旧 Windows 没有实机验证。
