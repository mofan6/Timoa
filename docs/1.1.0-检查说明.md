# Timoa 1.1.0 预览检查

## 范围

按要求只进行编译检查、翻译表检查和代码层面的简单逻辑检查。
没有打开实际窗口进行交互、截图、视觉排版或实际闹钟响铃检验。
最终程序启动后交由用户检查；本次不生成安装包或发布压缩包。

## 已通过

- Release 编译，Windows x64，静态语言运行时。
- 简体中文、繁体中文、英文：所有界面翻译键均有对应文案。
- Git 差异空白检查。
- 13 项无窗口逻辑检查：
  1. 倒计时暂停、继续、重置保留原时长。
  2. 单一专注移除后恢复空闲，其他原有计时保留。
  3. 自然结束的倒计时只累计一次。
  4. 正计时只累计运行时间，完成本轮不重复累计。
  5. 正计时重置不增加总专注时长。
  6. 新设置与正计时备份数据可往返，重新打开时正计时恢复为暂停。
  7. 旧备份采用新字段默认值，原有页面编号不变。
  8. 精简窗提醒只选取已启用且处于未来 30 分钟内的闹钟，并按时间排序。
  9. 启动正计时会暂停全部运行中的倒计时，并保留各自剩余时间。
  10. 启动倒计时会暂停正计时，保留已用时长。
  11. 继续或重新运行倒计时与正计时互斥；仅重置暂停中的倒计时不打断正计时。
  12. 精简窗显示当前运行的计时；选中正计时后，未开始或暂停时也能显示正计时。
  13. 切换正计时时，已到期倒计时仍能交付一次完成提醒。

## 人工代码核对

- 单一专注开始后使用只读时间显示，移除后恢复原始时长和设置控件。
- 通知条沿用页面内容右侧 20px 留白，显示后 10 秒自动消失。
- 两个窗口共用同一调度器和持久化状态，关闭到托盘不结束计时。
- 精简窗回到完整窗口时保留原页面与窗口大小；精简窗尺寸不写入主窗口设置。
- 主窗口和精简窗均使用 Slint `WindowMoveArea`。不再从 `TouchArea.pointer-event` 同步发送系统拖动消息；由 winit 管理拖动状态并在结束时补回鼠标释放事件，避免指针捕获残留。
- 标题栏绘制扩展到客户区，保留系统缩放边框和 DWM 圆角、阴影；具体外观仍待用户检查。
- 旧版成品保留，当前安装目录的旧程序文件没有被覆盖。

## 预览反馈修复

- 更多设置使用矢量折线箭头，移除可能缺字的 Unicode 箭头字符；展开触发区域限定在标题行。
- 感叹号视觉直径 12px，独立保留 30×30px 悬浮区域；100ms 后显示说明，跟随鼠标并向下避让 28px。说明使用主窗口内无输入处理的覆盖层，避免弹出窗口捕获鼠标。
- 更多设置标题行移除整块悬浮底色；音频试听改为 30px 圆形播放/暂停图标，继续调用原有试听/停止逻辑。
- 单一专注、正计时默认关闭；保留已有用户选择。浅色/深色通过统一 Theme 提供，新提示与按钮包含简体、繁体、英文文案，全部界面翻译键完整覆盖。
- 精简窗移除内部重复圆角边框，统一由 DWM 绘制边框、圆角与阴影；背景填满客户区，消除内外圆角叠加。
- 主窗口与精简窗共用原生边缘/四角命中检测。精简窗默认宽 280px、最小宽 248px、最小高 116px（有临近提醒时 148px），没有固定最大尺寸；数字、状态、进度与提醒随尺寸布局，数字字号同时受宽高限制。精简窗尺寸不覆盖主窗口保存尺寸。
- 两个拖动入口、缺字箭头移除、提示区域、边缘缩放和无重复圆角的静态检查通过。
- 本次继续只编译和检查代码，没有实际窗口拖动、点击或截图验证。

## 浅色界面与精简窗调整

- 标题栏小图标改为在 32px 标题行内显式垂直居中，消除固定高度图像默认贴到顶部的问题；标题按钮继续使用矢量图形。
- 浅色倒计时和正计时卡片背景与其他卡片相同，深色 `#1e1c17` 保持原值。
- 周视图左右箭头改为 16px 矢量折线，消除放大文字字形造成的基线偏移。箭头与日期共用 36px 行高并按几何中心定位，保留原有换周逻辑与按钮反馈；辅助功能名称提供三语文案。
- 精简窗默认宽从 360px 缩至 280px，允许继续缩至 248px；标题左对齐 16px，两个窗口按钮靠左收紧，内容两侧留白统一。
- 新增透明底浅色 `logo-light.svg`，仅在页面内的 `AppLogo` 随主题切换；原 `logo.svg`、`timoa.ico`、各窗口原生图标与桌面快捷方式图标不变。
