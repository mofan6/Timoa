# 1.3.0 渲染与提醒调度说明

## 默认渲染方式

默认成品使用软件渲染，避免为窗口创建 OpenGL 驱动上下文。保留 Slint
`accessibility`，不把移除读屏支持作为降低内存的手段。源码提供可选的 `gpu`
编译特性；普通发布包不包含该后端。

软件渲染器中的原生字体适配继续使用相同的字体匹配与字形编号，字形覆盖图由
DirectWrite 产生，失败时回退 Swash。字库共享、16 项字体面缓存和 1 MiB
字形缓存的边界见 vendor/i-slint-renderer-software/Timoa-NATIVE-FONTS.md。

Slint 1.18.1 的软件图像着色不支持渐变，框阴影也未实现。因此主题按钮将渐变
放进 SVG 本身，名称菜单使用可拉伸的 SVG 阴影。主题色、几何尺寸和布局继续
来自原有界面定义。`tools/generate-themes.py` 同时生成配色、图标与按钮资源。

## 提醒状态

- 一个 `AlertWindow` 延迟创建并复用，回调读取当前提醒状态。
- 原生关闭请求只结束当前提醒；下一次 100 ms 调度再显示排队项，避免工具包
  在回调结束后隐藏刚复用的下一条提醒窗口。
- 倒计时、闹钟与提前提醒优先于整点/半点通知。报时等待超过 30 秒便作废，
  避免阻塞解除后显示过时的时间提示。
- 提示音在到时事件中播放，不等待弹窗队列。关闭旧提醒只停止其自己拥有的
  提示音，不停止较新提醒正在播放的声音。
- 创建提醒组件成功后才消费队列，组件创建失败时保留待显示提醒。

## 分发与检查范围

便携版保留链接器产生的普通 PE，安装包使用 LZMA 固实压缩。文件增大与内存
使用是不同的指标；不把其他机器、其他工具链的 PR 内存数据作为本版测量结果。

发布编译与静态包检查结果见 release-1.3.0-package-review.json。检查包括
x64/x86、Windows 7 子系统基线、已知硬导入阻碍、版本资源、安装包内嵌 EXE
与便携版及原始编译结果的 SHA-256 一致性。

`examples/render.rs` 可在不打开原生窗口、不读取用户数据的情况下导出软件
渲染页面，支持语言、深浅模式和主题序号，第六个参数 `palettes` 输出十二种
主题组合。该离屏绘制不等同于系统交互、提醒响铃或旧 Windows 实机验证。

未新增或运行自动化测试，未执行安装器，未修改用户启动项或导入实际用户备份。
打包时旧版仍在运行，未结束该进程，也未执行会与其争用单实例标识的内存采样。
