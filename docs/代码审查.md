# V1.0.1 发布前代码与逻辑审查

范围：JSON 备份导出、导入、Windows 开机启动与安装器衔接。
方式：阅读源代码与调用路径；未实际导出或导入文件，未操作启动注册表、安装/卸载或重启 Windows。

## JSON 导出

- `export_data` 从引擎取得快照，包括暂停/完成状态、剩余时间、绝对截止时间、计划、设置及专注累计值。
- 保存框取消时不修改数据；UTF-8 JSON 经同目录临时文件、同步写盘、Windows 原子替换保存。
- 无写入权限、磁盘等错误反馈到页面，不报告成功。
- JSON 保存自定义声音的名称和编号；按产品设计，不包含音频文件本身。

## JSON 导入

- 文件读取前及解析时均限制为 5 MB，解析失败不修改现有计划；未知格式版本拒绝导入。
- 当前格式要求设置对象与两组计划数组齐全，避免将缺失字段的文件当作空备份。
- 兼容已有旧格式，导入字段会进行范围、重复编号、条目数量与时间校验。
- 需确认后才导入；取消不修改计划。确认前重新取得现有快照，保存为 `data-before-import.json`。
- 候选引擎先生成并原子持久化，失败时保留当前引擎；成功后才替换调度器、停止旧提醒并清空旧编辑草稿。
- 导入设置时应用语言、主题、窗口尺寸、页面和默认声音；不导入设置时保留当前偏好。
- 开机启动状态以当前 Windows 注册状态为准，JSON 中的布尔值不自动修改系统启动项。
- 音频转换正在运行时拒绝确认导入，避免后台导入结果写入刚替换的声音列表。

## 开机启动

- 使用当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`（兼容已有 `TIMO` 键名），不要求管理员权限。
- 路径有双引号并附加 `--startup`，支持路径中的空格和中文；程序移动后需要在最终位置重新开启。
- 状态读取核对当前 EXE 的完整命令与存在性，并读取 `StartupApproved\Run` 的禁用标志。
- 用户在 Timoa 内主动开启时清除本程序已有的禁用标记；失败会反馈错误。
- 关闭只删除本程序启动项；恢复默认设置会关闭启动项，保留计划、声音列表及累计时长。
- `--startup` 隐藏主窗口进入托盘，继续调度；已有实例时静默退出，普通手动启动才唤起已有实例。
- 安装器在已有启动项时将其路径接续为安装目录中的 Timoa.exe，保留 Windows 禁用偏好。
- 卸载器只移除指向自身安装路径的启动项，不删除用户的计划和自定义声音。

## 审查结论的范围

上述调用链在代码上具备成功、取消与主要错误分支，已修正导入界面偏好未应用、导入落盘失败仍替换引擎、启动状态只检查键存在及启动路径迁移问题。
实际功能受文件权限、磁盘状态及 Windows 启动策略影响；本次未进行运行验证，因此结论不等同于实际环境验证通过。
