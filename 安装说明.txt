Timoa 1.1.5

Windows 10 / 11 64 位：Timoa.exe、Timoa-Setup.exe。
Windows 7 SP1+ 64 位：Timoa-1.1.5-Win7-x64.exe、Timoa-1.1.5-Win7-x64-Setup.exe。
Windows 7 SP1+ 32 位：Timoa-1.1.5-Win7-x86.exe、Timoa-1.1.5-Win7-x86-Setup.exe，需要 SSE2。

单 EXE 可直接运行；Setup 安装到当前用户目录，无需另装语言运行库。
升级或切换版本前，请从右下角托盘退出旧版。三个版本共用数据目录和单实例标识。
数据目录：%APPDATA%\TIMO。自定义音频在其中的 sounds 文件夹。
JSON 备份包含计划、设置和专注统计，不包含自定义音频文件。

源码包包含 normal 与 windows7 两套独立源码。正常版源代码与 Win7 适配分别维护。
Win7 包经过编译和静态 PE 检查，尚未在 Windows 7 真机或虚拟机上运行验证。
